# AgentTelemetry 2.2.0 (beta 1)

AgentTelemetry 2.2.0 beta 1 is a **pre-release** for people who want the next version early. The stable
release is still 2.1.0, and it stays the default download, Marketplace and Open VSX listing, and PyPI
package until 2.2.0 is released. A beta app installs over a stable one (it is the same app); to go back,
install 2.1.0 again. Your ledger and settings carry over either way.

## What's new

- **Antigravity.** Conversations from the Antigravity app, IDE and CLI are read from their local
  databases: tokens, models, tools and session timelines, with fields Antigravity does not record shown
  as unavailable.
- **Cursor, first class.** Per-message dates, recorded usage, tool activity, workspace attribution and
  session timelines from Cursor's local storage. History that Cursor later deletes stays counted.
- **Codex's compressed rollouts.** Codex compresses idle threads (`*.jsonl.zst`). They are now read, so
  idle threads stay live, renameable and counted instead of being archived. Decoding uses Python 3.14+ or
  the `zstd` command; the apps include it.
- **Usage a tool deletes stays counted.** When OpenCode, Hermes, OpenClaw, Claude Code or Copilot removes
  sessions or messages from a log that is still on disk, the usage already recorded is kept.
- **Prices.** GPT-6.1 Terra is priced (it showed $0). Gemini 4 Argon's announced price increase is dated
  2026-12-01 and applies only from then.
- **AgentTelemetry Pulsar.** The log-reading engine (`parser.py`) now has a name in the docs and the app.
- **Editor extension 2.1.1 (pre-release).** An **Active now** section lists the sessions active in the last
  15 minutes. **Get the desktop app** appears where the extension cannot start Python, and the Marketplace
  and Open VSX pages link the desktop apps and the product page.
- **Tidier dashboard.** The "What changed?" card is gone from Overview and Cost, and the sidebar no longer
  shows the log count and date range. A link to the dashboard from another site (such as AgentTelemetry
  Pro's "Open local dashboard") opens the page instead of an error.
- **Windows.** A backend still doing its first parse is no longer reported as a failed start, and the
  installer can be signed when a signing command is configured.

## Removed: the Optimize tab and the local MCP bridge

Both now belong to AgentTelemetry Pro. Releases up to and including 2.1.0 keep them; 2.2.0
of the open-source app does not include them.

- **Optimize tab.** The sidebar entry and its suggestions are gone. A saved `#optimize`
  link or bookmark opens Overview. The Tools & agents tab keeps its **MCP servers** table
  (which servers your agents called, and tools used out of those offered): that is usage
  telemetry, not the bridge.
- **Local MCP bridge.** `mcp_server.py`, its backend route and the Settings panel are
  removed, with no stub. An AI client still configured with the old command fails to start
  that server.

### Cleanup if you enabled MCP in 2.1.0

1. Remove the `agent-telemetry` server from each MCP client where you pasted the generated
   configuration (for example Claude Desktop's `claude_desktop_config.json`, `~/.claude.json`,
   Codex's `~/.codex/config.toml`, or Cursor's `mcp.json`).
2. Optionally delete `mcp-access.json` and `mcp-access.lock` from the
   `AgentTelemetryNative` folder (macOS `~/Library/Application Support/AgentTelemetryNative`,
   Windows `%LOCALAPPDATA%\AgentTelemetryNative`, Linux
   `${XDG_STATE_HOME:-~/.local/state}/AgentTelemetryNative`). They hold an access key that
   2.2.0 no longer accepts anywhere; nothing deletes them for you.

Your ledger, cache, filters and saved views are unchanged. There is no rebuild and no cache
migration for this removal.

## Upgrading

The ledger moves to cache version 64 on the first start. Every existing entry is kept, including archived
history; Codex's compressed rollouts appear beside the entries they replace. Do not run `--rebuild`: it
discards history whose logs are gone.

Cost figures are estimates at published API list prices, not provider bills or subscription charges.
Coverage and detail depend on what each coding tool records.
