## What's new

- **New models are priced.** These showed $0 before:
  - **GPT-6.2 Astra:** $8 input and $40 output per million tokens, $0.40 cached, $10 for a 30-minute cache write.
  - **GPT-6.2 Sol:** $2 / $10, $0.10 cached, $2.50 cache write.
  - **MAI Code 2:** $0.50 / $2.50, $0.025 cached. **MAI Code 2 Flash:** $0.05 / $0.25, $0.005 cached. Both are promotional rates through May 17, 2027.
  - **Gemini 4 Neon:** $3 / $15, $0.15 cached.
  - Prompts over 272K tokens and the Fast and Ultrafast tiers are not modeled, as for GPT-6.1, so their cost shows at the standard rate.
- **Every spelling of the Microsoft models is recognized.** OpenCode's lower-case `mai-code-2` and `microsoft/...` ids read $0 before; they now match the priced names. Gemini 4 Neon is named the same way from every tool.

## Upgrading

No ledger change: the cache stays at version 64 and nothing is re-read. Install over 2.3.1 or earlier; history is kept. Do not run `--rebuild`. Prices apply when a day's cost is shown, so past days with these models update on their own.

Cost figures are estimates at published API list prices, not provider bills or subscription charges.
