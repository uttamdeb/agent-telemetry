# AgentTelemetry 2.2.1

AgentTelemetry 2.2.1 lets the editor extension's Agent desk read the AgentTelemetry Pro app on computers that have
only the Pro app, fixes the release-notes link in the desktop apps, and points to the optional Pro add-on. The app's
usage figures, parser and ledger are unchanged from 2.2.0. This is the first beta, `v2.2.1-beta.1`.

## What's new

- **The Agent desk works with the AgentTelemetry Pro app.** When no free AgentTelemetry service runs on the default
  port, the editor extension reads the Pro app's local service instead (Stable on port 7888, Beta on 7889) and says
  "Connected to AgentTelemetry Pro". The free service always wins when it runs, moving between the two starts the
  figures afresh, and a port you set yourself is the only one used.
- **Release notes link fixed.** In the macOS and Windows apps, "Read on GitHub" in the What's new dialog pointed at
  `/releases/tag/2.2.0`, a page that doesn't exist; it now opens the `v`-tagged release page.
- **Pro is mentioned.** The README and the extension's store page say what the optional AgentTelemetry Pro add-on
  adds and link the Free vs Pro comparison.

## Upgrading

No ledger change: the cache stays at version 64 and nothing is re-read. Install over 2.2.0; history is kept. Do not
run `--rebuild`.

Cost figures are estimates at published API list prices, not provider bills or subscription charges.
