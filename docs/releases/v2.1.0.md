# AgentTelemetry 2.1.0

AgentTelemetry 2.1.0 brings the original native app release forward with the reviewed
dashboard, MCP, editor, telemetry, and native-client improvements made since 2.0.0.
All components in this release use version 2.1.0.

The native app includes Python and runs the same local dashboard on macOS and Windows.
There is no native Linux tray app in 2.1.0; Linux users can run the browser dashboard
from the Python package or source checkout. The MCP
bridge is included in the Python package and native/editor backend; it is read-only, uses
stdio, requires an already-running dashboard, and remains off until enabled in Settings.
It is a component of AgentTelemetry 2.1.0, not a separate marketplace download.

## What's included

- **Local dashboard and native clients:** macOS menu bar and Windows system tray apps,
  recent-session activity, local-server controls, shared refresh behavior, release notes,
  and the same local ledger and backend.
- **Session and delegation detail:** clearer main-agent and subagent views, recorded
  parent navigation where the source provides it, Claude and Codex reasoning-effort labels,
  source-recorded model and tool activity, compactions, and timeline filtering.
- **Copilot telemetry:** workspace attribution, named SDK child sessions, improved usage
  accounting and compaction labels, and explicit reporting limits for partial SDK totals.
- **Agent desk extension:** workspace-first usage, linked sessions and delegation, live
  recorded-usage counter, native activity sidebar, and dashboard access. The same
  cross-platform VSIX is listed separately in Microsoft Marketplace and Open VSX.
- **Read-only local MCP:** eight analytics tools for usage, comparisons, insights, sessions,
  timelines, data health, dimensions and saved subscription-limit observations. Access and
  optional data scopes require separate consent.
- **History and project continuity:** safer project relocation handling, ledger backups and
  recovery, and preserved archived history during supported metadata upgrades.

Cost figures are estimates at published API list prices, not provider bills or subscription
charges. Coverage and detail depend on what each coding tool records. The macOS DMGs and
Windows installer are unsigned/unnotarized; review the linked release installation notes
and checksums before installing.
