## What's new

- **New models are priced.** These showed $0 before:
  - **Claude Fable 5.2 and Mythos 5.2:** $8 input and $40 output per million tokens, with $0.20 cache reads. Fast mode is $16 / $80.
  - **Gemini 4 Carbon:** $2 / $10, $0.10 cached, through November 30, 2026. Google doubles its price on December 1.
  - **Gemini 4 Hydrogen:** $1.50 / $7.50, $0.075 cached.
  - Fable and Mythos used from OpenCode, Hermes or Cursor are now named and priced too.
- **Sonnet 5.5's cheaper cache reads are counted.** Anthropic cut them from $0.20 to $0.10 per million tokens on October 7, 2026. Usage from that day on uses the new rate, and earlier days keep the old one.
- **Rename reaches every session.**
  - **Codex:** the Mac and Windows apps now find Codex in the ChatGPT app, the Codex editor extension or the Codex desktop app, even when no `codex` command is on your PATH. Before, every Codex session said "Codex's local CLI is required".
  - **Copilot, Cursor, Claude Desktop, Antigravity, Hermes and OpenClaw:** these have no title AgentTelemetry can safely edit, so they now offer **Name in AgentTelemetry**, as Claude subagents already did. The name is kept on this device only, and the tool's own files are never written.

## Upgrading

No ledger change: the cache stays at version 64 and nothing is re-read. Install over 2.2.3 or earlier; history is kept. Do not run `--rebuild`.

Cost figures are estimates at published API list prices, not provider bills or subscription charges.
