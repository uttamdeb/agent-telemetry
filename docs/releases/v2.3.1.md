# AgentTelemetry 2.3.1

AgentTelemetry 2.3.1 makes renaming a running Claude Code session honest: it says so up front instead of saving a name that Claude Code would put back. This is the first beta, `v2.3.1-beta.1`.

## What's new

- **Renaming a Claude Code session that is still running says so before anything is saved.** Claude Code keeps a running session's name in memory and writes it to the transcript again on its next turn, so a new name saved from AgentTelemetry did not last. Rename now checks Claude Code's own session list on this computer. If the session is running, it explains why and suggests `/rename` in Claude Code, or renaming here after you close the session. The check runs again just before the name is written. Closed sessions rename as before.

## Upgrading

No ledger change: the cache stays at version 64 and nothing is re-read. Install over 2.3.0 or earlier; history is kept. Do not run `--rebuild`.
