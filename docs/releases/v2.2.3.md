# AgentTelemetry 2.2.3

AgentTelemetry 2.2.3 gives the theme button a different icon for each mode. The app's usage figures, parser and ledger
are unchanged from 2.2.1. This is the first beta, `v2.2.3-beta.1`. There is no open-source 2.2.2 release: that number
went to an extension pre-release on Open VSX and to AgentTelemetry Pro 2.2.2, which is built on this code.

## What's new

- **The theme button shows the mode it is in.** It used to show the same half-filled circle in every mode. It now
  shows a sun for Light, a moon for Dark and the half-filled circle for Auto, and its label names the mode ("Theme:
  Dark. Change theme"). The editor extension's bundled dashboard gets the same button.
- Everything in 2.2.1 beta 1: the Agent desk reads the AgentTelemetry Pro app's local service when no free service is
  running, and the What's new dialog's "Read on GitHub" link opens the right release page.

## Upgrading

No ledger change: the cache stays at version 64 and nothing is re-read. Install over 2.2.0 or 2.2.1 beta; history is
kept. Do not run `--rebuild`.

Cost figures are estimates at published API list prices, not provider bills or subscription charges.
