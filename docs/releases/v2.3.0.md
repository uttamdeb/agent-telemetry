# AgentTelemetry 2.3.0

AgentTelemetry 2.3.0 is the stable release of the 2.2.1 to 2.2.4 betas. The editor extension works with AgentTelemetry Pro. The newest Claude and Gemini models are priced, every session can be renamed, and the theme button shows its mode. All components in this release use version 2.3.0.

## What's new since 2.2.0

- **New models are priced.** These showed $0 before:
  - **Claude Fable 5.2 and Mythos 5.2:** $8 input and $40 output per million tokens, with $0.20 cache reads. Fast mode is $16 / $80.
  - **Gemini 4 Carbon:** $2 / $10, $0.10 cached, through November 30, 2026. Google doubles its price on December 1.
  - **Gemini 4 Hydrogen:** $1.50 / $7.50, $0.075 cached.
  - Fable and Mythos used from OpenCode, Hermes or Cursor are named and priced too.
- **Sonnet 5.5's cheaper cache reads are counted.** Anthropic cut them from $0.20 to $0.10 per million tokens on October 7, 2026. Usage from that day on uses the new rate, and earlier days keep the old one.
- **Rename reaches every session.**
  - **Codex:** the Mac and Windows apps find Codex in the ChatGPT app, the Codex editor extension or the Codex desktop app, even when no `codex` command is on your PATH.
  - **Copilot, Cursor, Claude Desktop, Antigravity, Hermes and OpenClaw:** these offer **Name in AgentTelemetry**, a name kept on this device without touching the tool's files.
- **The editor extension works with AgentTelemetry Pro.** When no free AgentTelemetry service runs on the default port, the Agent desk reads the Pro app's local service instead (Stable on port 7888, Beta on 7889) and says so.
- **The theme button shows its mode:** a sun for Light, a moon for Dark and a half-filled circle for Auto.
- **Release notes link fixed.** "Read on GitHub" in the apps' What's new dialog opens the right release page.

## Upgrading

No ledger change: the cache stays at version 64 and nothing is re-read. Install over 2.2.0 or any 2.2.x beta; history is kept. Do not run `--rebuild`.

Cost figures are estimates at published API list prices, not provider bills or subscription charges.
