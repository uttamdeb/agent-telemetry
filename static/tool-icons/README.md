Bundled locally for offline display. Brand marks belong to their respective owners;
these small references identify the tool and imply no affiliation or endorsement.
Codex uses OpenAI; Claude Code/Desktop use Claude (Anthropic); the remaining tools
use their own published marks. Shapes and original SVG colors are unchanged.
Monochrome marks render black/white for theme contrast.
